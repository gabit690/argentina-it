# Argentina IT

Información de contacto de empresas del rubro IT en Argentina.

## Demo

https://argentina-it.vercel.app

## Stack

- Astro
- TypeScript
- CSS3
- Preact
- Eslint
- Husky
- Prettier
- Vitest

## Datos

Los datos recopilados hasta ahora corresponden a empresas ubicadas en el distrito tecnológico de Parque Patricios (CABA).
